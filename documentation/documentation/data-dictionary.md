# Data Dictionary — salesdata
| Column | Description | Data Type |
|---|---|---|
| order_id | Unique identifier for each order | Number |
| order_date | Date the order was placed | Date |
| customer_id | Unique identifier for each customer | Number |
| product_category | Category or type of product purchased in the order | Text |
| region | Region from where the product was purchased | Text |
| quantity | Order quantity from the customer |  Number |
| unit_Price | Price per product | Number |
| discount | Discount received when purchased | Number |
| payment_type | Medium of payment | Text |
| delivery_days | Time it takes to deliver the product | Number |
| revenue_inc_dis | Amount of sales generated after discount | Number |
| revenue_exc_dis | Amount of sales generated before discount | Number |
| delivery_status | Status of the delivery, i.e slow, normal, Fast | Text |
| revenue_band | Band of the revenue from high to low | Text |
| year | Year that the product gets sold | Number |
| month | Month that the product gets sold | Text |
